How progress and ranks work

The values below match the XP and strength calculations used by Habitline.

What earns XP

XP is saved when an eligible action completes. Editing the same record does not create an extra award.

Overall XP ranks

Your overall rank combines habits, training, journaling, goals and completed kickboxing audio repetitions. Planner and food tracking do not award XP.

Choose how much each completed action earns. Existing awarded XP stays unchanged.

How workout XP is calculated
The first saved session for an exercise earns the first-session value. Every later session is compared with the immediately previous session for that exercise. If weight, sets or reps is higher, it earns the improvement value once; otherwise it earns the standard workout value. It does not award three separate bonuses.

Resetting returns your visible level to F with 0 XP. It does not delete habits, workouts, food, journals or any other history.

Install Habitline on iPhone

Connect the phone and PC to the same Wi-Fi, keep Habitline running on the PC, then open the private link below on the phone. Anything logged on either device updates the same data immediately.
On iPhone: open the link in Safari, tap Share, choose Add to Home Screen, then tap Add. Habitline will appear as an app icon and open without Safari controls.
If Windows asks about firewall access, allow Habitline on private networks. The app uses this PC as its private data server, so the PC must be on and Habitline must be running.
